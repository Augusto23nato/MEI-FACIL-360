# Lampejo

Seu professor particular de bolso: diga o que quer aprender e uma aula curta abre no navegador —
explicação com chat, vídeo-fluxograma narrado, ilustrações e uma prova oral de 3 perguntas.

## Como instalar
1. Descompacte o `Lampejo.zip`.
2. Abra a pasta `Lampejo` no Claude Code (no terminal: `cd Lampejo` e depois `claude`).
3. Diga: **configurar o Lampejo**. O Claude conduz tudo: instala os programas, abre o cadastro do
   ElevenLabs, valida sua chave, deixa você escolher a voz e testa uma aula de verdade.

## Como usar
Depois do setup, é só dizer: *"quero aprender juros compostos"*, *"me explica machine learning"*,
*"aula de fotossíntese"*.

## Do que precisa
- Claude Code com login na sua conta do Claude (as aulas saem da sua assinatura).
- Uma conta no ElevenLabs (o plano gratuito serve para começar) — é a voz do narrador e quem entende
  o que você fala no microfone.
- Opcional: chave do OpenRouter para o slide de ilustrações (cerca de US$ 0,03 por imagem).
- Mac (recomendado) ou Linux. No Windows, siga as instruções que o setup mostra.

Suas chaves ficam só no seu computador, em `.lampejo/config.env`. As aulas ficam em `runs/`.
